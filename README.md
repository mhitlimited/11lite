# CPbOX - Facebook Lite & Messenger Resource Hub

A lightweight, fast-loading static website for organizing and providing download resources for Facebook Lite, Messenger, and APK files. Designed for users seeking optimized versions of popular applications.

## 📋 Overview

CPbOX is a resource hub that aggregates official download links and verified APK repositories in one convenient location. The website is optimized for performance, accessibility, and user experience across all devices.

**Live Site:** https://mhitlimited.github.io/11lite/

## 📄 Website Pages

### Main Pages
- **`index.html`** — Homepage with navigation and featured downloads
- **`pages/apk.html`** — APK library and download options
- **`pages/facebook-lite.html`** — Facebook Lite download links
- **`pages/messenger.html`** — Official Messenger download information

### Collection Pages
- **`Allapk.html`** — Complete app collection and version history
- **`fb11lite.html`** — Facebook Lite version archive
- **`messenger3.html`** — Messenger version collection
- **`Messenger3.html`** — Compatibility version (mirrors `messenger3.html`)
- **`fb11ite.html`** — Redirect page to `fb11lite.html`

## 🎨 Assets & Resources

### Stylesheets
- **`assets/css/style.css`** — Main website styling and responsive design
- **`style.css`** — App collection pages styling and theme support

### Scripts
- **`assets/js/script.js`** — Automatic footer year updater
- **`script.js`** — Advanced features:
  - Theme switcher (dark/light mode)
  - Navigation menu handling
  - Multi-language support
  - Download interaction handlers

### Web App Configuration
- **`assets/manifest.webmanifest`** — PWA configuration for web app installation

## 📥 Download Source Policy

We maintain strict quality and safety standards:

- ✅ **Official Sources:** Prioritize Google Play Store and official publisher links
- ✅ **Verified APKs:** Only link to trusted, verified repository release assets
- ✅ **Security Verification:** Review APK integrity, permissions, and source authenticity
- ✅ **User Responsibility:** Users are responsible for downloads, installations, and usage compliance
- ⚠️ **Disclaimer:** This website provides information and links only; we are not responsible for third-party content or usage

## 🚀 Quick Start

### Local Development

Preview the website locally using Python's built-in server:

```bash
# Navigate to repository root
cd 11lite

# Start local server on port 8000
python3 -m http.server 8000
```

Then open your browser and visit:
- **http://localhost:8000/**

### Requirements
- Python 3.x installed
- No additional dependencies required
